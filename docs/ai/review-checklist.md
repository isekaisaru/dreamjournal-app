# YumeTree レビューの観点

> 一行まとめ: **このアプリで「壊れたら一番困る所」の一覧**。Antigravity にはこのファイルを指定して読んでもらいます（Codex は自動では読まないので、使うときは `@codex review docs/ai/review-checklist.md の観点で` とコメントします）。

このリポジトリは、夢の記録アプリ YumeTree（ユメツリー）です。
フロントは Next.js 16（`frontend/`、Vercel）、バックエンドは Rails 8.1 API（`backend/`、Render）、DB は Supabase の PostgreSQL です。

## 書き方

- レビューコメントは **日本語** で書いてください。開発者は学習中なので、専門用語には一言の説明を添えてください。
- 1 つのコメントには「どのファイルの何行目か」「どんな入力や操作で壊れるか」「直し方の例」を入れてください。
- 好みの問題（書き方の揺れ・命名の好み）は指摘しないでください。動作・安全性・データの壊れ方を優先します。
- 重要なものから、最大 10 件までにしてください。

## 特に見てほしいこと

1. **認証と Cookie**: JWT は HttpOnly Cookie で運びます。トークンを `localStorage` やレスポンス本文、ログ、Sentry に出す変更は重大な問題です。
2. **秘密情報**: API キー・パスワード・トークンの直書きは重大な問題です。値は環境変数から読みます。
3. **DB の変更（`backend/db/migrate/`）**: 列や表の削除、`NOT NULL` の追加は、本番データを壊すおそれがあります。段階を分けているか（先にコードで使わなくする → 後で列を消す）、`backend/db/structure.sql` も更新しているかを確認してください。新しい表には RLS（行レベルセキュリティ）が必要です。
4. **Sentry に送るデータ**: 夢の本文・メールアドレス・トークンを送らないこと。送信前の許可リストを通しているかを確認してください。
5. **Stripe（決済）**: Webhook の署名確認を外す変更や、金額をフロントから受け取る変更は重大な問題です。
6. **AI の利用制限**: 画像生成はプレミアム限定、音声記録は無料プランで月 5 回まで、などの上限を、フロントだけでなくサーバー側でも守っているかを確認してください。
7. **Next.js の `page.tsx`**: App Router の `page.tsx` は決められた名前以外を `export` できません。ヘルパー関数は別ファイルに置きます。
8. **テスト**: 動きを変える変更には、テスト（Jest / RSpec / Playwright）の追加か更新が必要です。テストを消したりスキップしたりして緑にする変更は指摘してください。
9. **CI の実行環境**: `.github/workflows/` では `ubuntu-latest` を使わず、版を明示しています。

## 見なくてよいもの

- ロックファイル（`yarn.lock`・`Gemfile.lock`）の中身
- 画像ファイル
