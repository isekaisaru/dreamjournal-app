# 月ごとの利用レポート（M1「数える」）

AIの利用回数・画像生成・夢の記録・概算の費用を、**合計の数だけ**で表示する読み取り専用のコマンドです。
メールアドレスやユーザーIDなど、個人を特定できる値は出しません。

## 使い方

Render の Shell（本番の backend）で実行します。**本番での実行は運営者が行います。**

```bash
bin/rails "usage:report[2026-11]"
```

- 年月を省くと、日本時間の今月になります。
- データベースには書き込みません（`SELECT` だけ）。

## 出る内容

| 区分 | 中身 |
|---|---|
| ユーザー数 | いまのプラン（無料・プレミアム・お試し）ごとの人数と、その月に登録した人数 |
| AIの利用回数 | 夢の分析・音声の記録・月次サマリー・画像生成の回数（プラン別） |
| 夢の記録 | 書かれた夢の件数、夢を書いた人数、その月に何日書いたかの分布（1日／2〜3日／4〜7日／8日以上） |
| つづき具合 | お試しを除く利用者について、月をまたいで「最初に書いた日から最後に書いた日まで何日か」の分布（まだ書いていない／1日／2〜6日／7〜13日／14日以上）、14日以上つづいた人数（M4 の目安は3人以上）、「最後に書いてから何日たったか」の分布（7日以内／8〜30日／31日以上） |
| 概算の費用 | 回数 × 概算の単価（目安） |

## 数え方の決まり

- 月は **日本時間の1日0時** から数えます。
  - アプリの時刻は UTC なので、無料の月上限（分析・音声）は日本時間の1日9時に戻ります。レポートの月の区切りとは9時間ずれます。
- プランは **いまの状態** で分けます。月の途中でプランを変えた人は、今のプランに入ります。
- つづき具合は、その月の最後の日（今月なら今日）の時点で数えます。夢を書いた日は日本時間の日付です。
  - 「14日以上つづいた」は、最初と最後の日の間が14日以上あるという意味で、毎日書いたとは限りません。
- 音声の利用ログ（`audio_analysis`）は 2026-11-15 のリリース（#579）から記録しています。それより前の音声は数えられません。

## 本当の費用の出し方

レポートの「概算の費用」は、知識による単価（未確認）をかけただけの目安です。本当の費用は次の手順で出します。

1. OpenAI の利用画面（Usage）で、その月の実額（ドル）を見る
2. このレポートの回数と並べて、1回あたりの費用を出す（例：分析の実額 ÷ 分析の回数）
3. `backend/app/services/usage_report.rb` の `ESTIMATED_UNIT_COST_JPY` を、確かめた単価に直す

あわせて、Render・Vercel・データベース・メールの月額を書き出すと、「赤字にならない人数」を出せます（ロードマップ M1）。
