# YumeTree レビューの指針（Gemini Code Assist 用）

このリポジトリは、夢の記録アプリ YumeTree（ユメツリー）です。
フロントは Next.js 16（`frontend/`、Vercel）、バックエンドは Rails 8.1 API（`backend/`、Render）、DB は Supabase の PostgreSQL です。

## 書き方

- レビューコメントは **日本語** で書いてください。開発者は学習中なので、専門用語には一言の説明を添えてください。
- 1 つのコメントには「何が問題か」「どんな入力や操作で壊れるか」「直し方の例」を入れてください。
- 好みの問題（書き方の揺れ・命名の好み）は指摘しないでください。動作・安全性・データの壊れ方を優先します。

## 特に見てほしいこと

1. **認証と Cookie**: JWT は HttpOnly Cookie で運びます。トークンを `localStorage` やレスポンス本文、ログ、Sentry に出す変更は重大な問題です。
2. **秘密情報**: API キー・パスワード・トークンの直書きは重大な問題です。値は環境変数から読みます。
3. **DB の変更（`backend/db/migrate/`）**: 列や表の削除、`NOT NULL` の追加は、本番データを壊すおそれがあります。段階を分けているか（先にコードで使わなくする → 後で列を消す）、`backend/db/structure.sql` も更新しているかを確認してください。新しい表には RLS（行レベルセキュリティ）が必要です。
4. **Sentry に送るデータ**: 夢の本文・メールアドレス・トークンを送らないこと。送信前の許可リストを通しているかを確認してください。
5. **Next.js の `page.tsx`**: App Router の `page.tsx` は決められた名前以外を `export` できません。ヘルパー関数は別ファイルに置きます。
6. **Stripe（決済）**: Webhook の署名確認を外す変更や、金額をフロントから受け取る変更は重大な問題です。
7. **テスト**: 動きを変える変更には、テスト（Jest / RSpec / Playwright）の追加か更新が必要です。テストを消したりスキップしたりして緑にする変更は指摘してください。
8. **CI の実行環境**: `.github/workflows/` では `ubuntu-latest` を使わず、版を明示しています。
